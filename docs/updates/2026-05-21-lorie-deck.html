Calculation order

  1. Determine pricing mode: flat-rate route (recognized pair like QC -> O'Hare) OR hourly (local rides) OR distance (default).
  2. Apply customer category override (JD, Lockton, Investor, LJ Member).
  3. Compute base components: Trip fee, Mileage, Deadleg, Add'l Driver, Add'l Time, Tolls, Fuel Surcharge, After Hours.
  4. SECONDARY = base + Tax + Overnight + Per Diem + flat Gratuity.
  5. THIRD = SECONDARY + (% Gratuity x SECONDARY).
  6. GRAND = THIRD + (3% x THIRD) when paying by credit card.
