Change Log

Bounce Protection is Live

LandJet Growth Engine · May 12, 2026

Why this shipped

Three hard bounces in 34 minutes from the Investor Outreach campaign on Monday, May 11. All three were "address doesn't exist" errors. A burst of hard bounces is the worst signal for domain reputation. The system had no validation in place.

What changed

Apollo verification filter Live
Apollo lead pulls now skip any address Apollo flags as "guessed" or "unverified." Only verified addresses enter the system. This was the root cause -- guessed emails were what bounced.
Bounce auto-Block Live
When a bounce notification lands in the inbox, the system reads the recipient and auto-Blocks them. Same action as the manual Block button shipped last week.

How to verify

  1. Open the Outreach page — the three names above should not appear in any queue.
  2. Pull from Apollo on a cold campaign — the response will tell you if any were skipped as unverified.
  3. Check the do-not-contact list on the System page — those three names will be there.

Known dependency

Bounce auto-Block reads NDRs from the rlandry@landjet.com inbox. A 7-day scan returned only 10 messages, suggesting an Outlook rule is hiding bounce notifications. If you have a rule that touches "Undeliverable" / "Delivery Failure" / "Postmaster" emails, please disable it so the auto-Block feature can find them. Without that, protection still works the next time you forward me a bounce manually, but it won't be hands-off.
