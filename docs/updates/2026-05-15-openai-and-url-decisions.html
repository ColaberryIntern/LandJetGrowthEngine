Two operational decisions for you. Both are short to handle and unblock things going forward. Take 10 minutes when you have it.

1. Create your OpenAI account

Why now: the AI behind the message generation, inbound classifier, and quote drafter has been running on my personal OpenAI account. It works fine, but the bill should be on LandJet, and you should own the API key going forward. Yesterday's "all messages are the same" issue happened because my account ran out of credits -- once you own the account, you control the spend cap and the alerts.

5-minute setup:

  1. Go to platform.openai.com/signup and create an account using rlandry@landjet.com.
  2. Add a payment method: Settings → Billing → Payment methods → Add payment method. Use the LandJet card.
  3. Set a monthly spend limit so you never get surprise bills: Settings → Billing → Limits → Monthly budget: $50 (we're using under $20/mo right now, $50 gives headroom). Set the email alert at $40.
  4. Create the API key: Settings → API Keys → + Create new secret key. Name it "LandJet Growth Engine". Copy the key (it starts with sk-proj-...) -- you only get to see it once.
  5. Send me the key. Two options:
    • Reply to this email with the key in the body (Gmail to Gmail is encrypted in transit, fine for this).
    • Or text it to me, whichever you prefer.

What I'll do with it: drop the new key into the production server's config and rotate. Takes about 60 seconds. The system will start running on your account with no behavior change Ryan-side.

My pick if it were me: growth.landjet.com. Says exactly what it does.
Path B: Buy a brand new domain ($10-12/yr)
Standalone identity, separate from the marketing site. Cheap. Buy on Cloudflare Registrar (no markup) or Namecheap. Some available ideas:
  • landjetgrowth.com

  • mylandjet.com

How to buy: Cloudflare → Sign up → Domain Registration → search the name → checkout. Forward me the registration confirmation.

Recommendation: Path A. Same security profile, free, takes 5 minutes. You can always upgrade to Path B later if you want a separate identity.
