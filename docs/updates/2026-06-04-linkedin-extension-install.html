LandJet LinkedIn Assistant v1.0.22

Self-serve install guide. The extension lives in your Chrome browser, watches LinkedIn profile pages, and drops a small panel with your draft outreach message + a one-click "Copy + open Connect" button.

Before

Install 5 minutes

  1. Sign in to the LandJet Growth Engine
    Open http://95.216.199.47:4000 and sign in with your LandJet credentials. You should land on the Outreach page.
  2. Download the extension zip
    Click Download Extension in the top nav. The file landjet-extension-v1.0.22-rlandry.zip downloads with your API token already baked in -- no separate sign-in step needed inside the extension.
  3. Open the Chrome extensions page
    In Chrome, type chrome://extensions in the address bar and hit Enter. Flip the Developer mode toggle in the top right to on.
  4. Unzip the file
    Right-click the downloaded zip and choose Extract All (Windows) or double-click it (Mac). You will get a folder with files like manifest.json, content.js, etc.
  5. Load the unpacked folder
    Back on the chrome://extensions page, click Load unpacked in the top left. Pick the folder you just extracted. The extension should appear in the list as LandJet LinkedIn Assistant with version 1.0.22.
  6. Pin it (optional but recommended)
    Click the puzzle-piece icon in Chrome's toolbar, find LandJet LinkedIn Assistant, and click the pin icon next to it. The LJ icon now sits in your toolbar for quick status checks.

Use it

  1. Open any LinkedIn profile that has a lead in your queue today
    If the contact is in the Outreach queue with channel = LinkedIn Connect, the LandJet panel slides in on the right side. If nothing appears, the contact is not in today's queue (and you should not be sending them a connection request).
  2. Confirm the draft message looks right
    The panel shows the lead name, campaign, current step, and the AI-drafted note. Edit the textarea if you want to tweak. The clipboard updates as you edit.
  3. Click the big blue button
    Copy message + open Connect. Your message goes onto the clipboard immediately. The extension tries to open the Connect dialog automatically. If it does not open (LinkedIn changes their DOM frequently), click LinkedIn's own Connect button.
  4. On LinkedIn: Add a note → Ctrl+V → Send
    Click Add a note on the dialog, paste with Ctrl+V (or Cmd+V on Mac), click Send. The extension watches for the Send click and marks the lead Done in the outreach queue automatically.
Test mode safety: if Test Mode is on (default while you are getting comfortable), Send does NOT actually transmit. The extension still logs the action so you can see what would have happened. Flip Test Mode off in /outreach Settings when you are ready to send for real.

If something does not work

  • Panel does not appear on a profile. Make sure the contact is in today's Outreach queue with channel = LinkedIn Connect. Refresh the page. If still nothing, click the LandJet icon in the toolbar and check that the extension is enabled and your API token is saved.
  • "Copy + open Connect" works but Connect dialog does not open. Click LinkedIn's own Connect button. The clipboard already has your message. Proceed with Add a note → Ctrl+V → Send normally.
  • Add a note button does not click when you press the manual mode button. Click LinkedIn's Add a note button yourself. The state watcher will detect it and light up step 3.
  • You want the new "Lorie said this dead-leg quote should be 0" type of finding from your session forwarded back. In the extension panel, expand Manual mode and click Dump diagnostics. Copy the JSON output that appears in the textarea. Email it to Ali. He will ship a targeted fix the same day.
  • Wrong version shown. Visit /api/extension/version; should report 1.0.22. If not, re-download via the in-app button. If yes, delete the old unpacked folder, extract the new zip, Load unpacked again.

What "mark Done" means

When LinkedIn confirms the Send, the extension calls the outreach API and advances the lead to the next step in the sequence. The contact disappears from your daily queue and the next follow-up is scheduled per the campaign's delay setting (default 4 days for follow-ups). If you ever need to undo, the Reset button in /outreach Settings shows your last 30 test-mode advances and lets you back any of them out.
